# Assess Intel difficulty by crew profile

Intel derives separate Difficulty assessments for a Small Crew (one or two
miners) and a Full Crew (three or four) because game scaling changes enemy
pressure but does not erase the larger crew's ability to split objectives. The
presentation collapses matching assessments and names the crew-size condition
only when they differ, avoiding a hidden universal party-size assumption
without requiring saved personalization. Class- or build-specific counterplay
does not change either assessment. Both profiles
assume promoted players who know the mission mechanics and coordinate
competently, without assuming optimized builds or graybeard execution.

Each profile is calibrated within Dive kind. An Elite Deep Dive receives no
blanket grade promotion: its label distinguishes easier and harder EDD
configurations rather than pretending an `Easy` EDD has the same combat safety
as an `Easy` normal Deep Dive. Because each Intel assessment belongs to one
specific Dive, the presentation does not compare these relative grades across
Dive kinds or add a redundant kind qualifier.
