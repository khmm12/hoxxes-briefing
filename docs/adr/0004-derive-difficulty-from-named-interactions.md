# Derive Difficulty from named interactions

Intel derives Difficulty through ordered, named gameplay interactions rather
than additive scores and thresholds. Objective burden, Warning context, direct
Anomaly effects, Stage position, and Crew profile each contribute explicit
rule conditions documented in the calibration and covered by tests. This keeps
assessments traceable without uncalibrated weights or generated player-facing
explanations.

When several factors coexist, Intel takes the strongest applicable named rule;
it does not stack grades. A compound rule is justified only when the
combination creates a distinct failure mechanism or consumes the same execution
capacity in a way that none of its factors explains alone.
