# Fold resource runway through the Dive

Intel assesses Stages in order and carries a qualitative Resource runway
between them instead of treating Stage position as a monotonic difficulty
bonus. The fold starts Fresh, with full health and ammunition but no banked
Nitra, and derives Banked or Contested evidence from the preceding Stage's
known Objectives and Mutators under the Reference Crew assumption.

The Briefing does not expose actual Nitra deposits, mining decisions, health,
or ammunition, so Resource runway is not an inventory simulation. It may change
a grade only when a named interaction makes the carried reserve causally
decisive; otherwise it does not affect the grade and remains residual
uncertainty.

This is especially important for Point Extraction. On Stage 1, mining the first
resupply competes with an already running pressure clock. On a later Stage, a
banked reserve can make the same Objective easier despite higher Hazard or
earlier resource use.

Resource runway remains internal policy. Player-facing Intel exposes grades
only, with no resource warnings, carried-state labels, or generated causal text.
